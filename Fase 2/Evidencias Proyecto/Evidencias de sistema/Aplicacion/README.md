# Evidencias de sistema · Aplicación

El código de la aplicación está en la raíz de este repositorio (`lib/`, `android/`, `ios/`, `web/`).
No se mueve a esta carpeta para no afectar la compilación ni los despliegues.

| Entregable | Enlace |
|---|---|
| Código de la app (Flutter) | Raíz de este repositorio |
| Código del backend (FastAPI) | [github.com/francobarra-dev/agecare-backend](https://github.com/francobarra-dev/agecare-backend) |
| Versión web (MVP) | https://agecare-tan.vercel.app |
| Backend en Azure (documentación interactiva) | https://agecare-api-xnjbc.azurewebsites.net/docs |
| APK Android | Sección *Releases* de este repositorio |

Cuentas de demostración: `demo@agecare.app` (familiar), `cuidadora@agecare.app`, `medico@agecare.app` y `elena@agecare.app` (adulto mayor).
